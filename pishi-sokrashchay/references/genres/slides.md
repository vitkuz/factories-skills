# Слайды для презентаций

## Цель жанра и что нужно читателю

- **Слайды** — документ, где информация нарезана на экраны (тезисы, графики, схемы, скриншоты). **Презентация** — весь процесс встречи: спикер, показ, вопросы, общение. Слайды — лишь часть.
- Два режима:
  - **для выступления** — слайды дополняют речь (спикер говорит «42 проекта за год» — на экране крупно «42 проекта в 2025»);
  - **для рассылки** — слайды автономны, читаются без спикера.
- Самый частый офисный жанр: слайды-документ, которые рассылают заранее и обсуждают на встрече. Они должны читаться сами по себе и служить опорой для разговора.
- Читателю нужно: найти ответ на **свой** запрос как можно раньше, видеть, а не читать, быстро схватить выводы.

## Ключевые принципы

- **Одна аудитория — одна презентация.** Определить, кто аудитория (клиенты, инвесторы, сотрудники, пресса) и почему они сами захотели бы это смотреть. Ответ на их запрос — ближе к началу; остальное после; ненужное — удалить. Примеры — из отрасли аудитории. Типовые версии под сегменты дорабатываются под конкретного клиента.
- **Не читать с экрана.** Текст читается за секунды, а произносится в разы дольше. Варианты: разослать документ заранее и обсуждать; две версии (визуальная для экрана, полная для рассылки); папка с файлами вместо слайдов; одна версия, с которой работают вместе с аудиторией («прочитайте выводы — что обсудим первым?»).
- **Слайд — капсула смысла.** У каждого слайда заголовок: либо «о чём здесь» («Продажи в IV квартале»), либо «каков вывод» («Продажи в IV квартале: +23% к III»). Всё на слайде — по заголовку; больше нигде в презентации этой темы нет; материал не «перетекает» на следующий слайд.
- **Не помещается** → сократить текст; вынести справочные данные на отдельный слайд/в конец; уменьшить шрифт (для чтения, не для проектора — смело до 10–12 pt); разбить тему на подтемы. Пусто после раскрытия темы — нормально.
- **Визуальный центр, «лицо слайда».** Покажите, а не расскажите: график, схема, скриншот, фото продукта в деле, большое число, логотип в центре. Чисто текстовые слайды — между визуальными, не сплошь.
- **Информативные иллюстрации.** График с точкой сравнения (этот год поверх прошлого); скриншоты реальных отзывов, а не фото «недовольного человека»; схемы «было/стало». Никаких стоковых человечков, шестерёнок, стрелок — они не про вас. Исключение — типовые предметы.
- **Подписи дополняют, а не дублируют** изображение (не «Новое оборудование», а «Новое оборудование — российское, обслуживается на месте»).
- **«Провести за ручку»:** выноски, подписи на графике, подсветка строк таблицы. Оптимально 1–2 пояснения на иллюстрацию.
- **Перечни:** однородные элементы, согласованы с обобщающим словом, лучше глаголами («Запустить...», «Сократить...»), а не отглагольными существительными («Обеспечение повышения...»). Распутывать цепочки родительных падежей. Пункты примерно равной длины. Без вложенных перечней (подзаголовки или отдельный слайд). Нет перечисления — пишите абзацем.
- **Резюме ≠ выводы.** Резюме — повтор ключевых фактов. Выводы — ваша оценка. Оба можно ставить в начале, а не только в конце: занятый человек получит всё сразу и решит, куда углубляться.
- **Финальный слайд** — что делать дальше: контакты, кнопка, где узнать больше.
- Высший пилотаж — презентация без слайдов: живая работа с рабочими файлами, реакция на вопросы, тезис сначала произносится, потом фиксируется.

## Структура (слайды-документ для рассылки и обсуждения)

```
1. Титул: тема для [аудитория].
2. Резюме/выводы: главное на одном слайде (заголовок-вывод).
3. Ответ на запрос аудитории: «как мы решаем вашу проблему X» — с визуальным центром.
4–N. Слайды-капсулы: [заголовок-вывод] + [график/схема/скриншот] + [1–2 выноски] + [короткий текст].
N+1. Справочные данные / детали / методика.
Последний: что дальше — контакт, следующий шаг.
```

## Типичные ошибки → как исправить

| Ошибка | Исправление |
|---|---|
| Универсальная презентация «для всех» | Под конкретную аудиторию и её запрос |
| Рассказ о том, что интересно нам (наш крутой бэкенд) | О том, что интересно этой аудитории; бэкенд — для разработчиков |
| Спикер зачитывает слайд | Обсуждать, а не читать; или две версии |
| Слайд без заголовка; тема размазана по нескольким | Заголовок + капсула |
| Тезисы столбиком вместо визуала | Найти, что показать |
| Стоковые картинки | Реальные фото, скриншоты, схемы |
| Подпись повторяет картинку | Подпись добавляет факт |
| «Повышение обеспечения контроля исполнения...» | Глаголы, распутанные родительные |
| Пункты разной длины, вложенные списки | Выровнять, вынести, разбить |

## Пример

**До (заголовок + перечень):**
> Задачи отдела
> — Повышение уровня открываемости email-рассылок клиентской базы
> — Обеспечение безопасности передачи данных
> — Контроль исполнения поручений со стороны подрядчика в части соблюдения сроков

**После:**
> Задачи отдела на IV квартал
> — Поднять открываемость рассылок до 30%
> — Защитить передачу данных клиентам
> — Добиться, чтобы подрядчик соблюдал сроки

**До (подпись):** «График продаж за 2025 год». **После:** «Продажи 2025 поверх 2024: с июня обгоняем прошлый год».

## Чеклист перед отправкой

- [ ] Понятно, для кого презентация и какой их запрос; ответ на него — в начале.
- [ ] Определён режим: выступление или рассылка (или две версии).
- [ ] У каждого слайда заголовок («о чём» или «вывод»), тема не повторяется на других слайдах.
- [ ] У опорных слайдов есть «лицо» — информативная визуализация; стоковых картинок нет.
- [ ] Подписи и выноски дополняют, 1–2 на иллюстрацию.
- [ ] Перечни однородны, глагольны, равной длины, без вложенности.
- [ ] Текст почищен от языкового мусора.
- [ ] Есть слайд резюме/выводов (в начале или в конце).
- [ ] Последний слайд — следующий шаг и контакт.
