# Промостраница (лендинг) и презентация продукта

## Цель жанра и что нужно читателю

- Страница, предлагающая **один** продукт (товар, услугу, курс, подписку), который можно сразу купить/заказать. Сюда «приземляются» с рекламы.
- В отличие от карточки интернет-магазина (помогает уже мотивированному выбрать), промостраница должна помочь **не слишком мотивированному читателю захотеть** конкретный продукт.
- Главная задача — дать читателю увидеть, **каково ему будет с продуктом**: соответствие его задачам, желаниям, страхам, мечтам. Не «наши преимущества», а «ваша жизнь с этим».
- Люди покупают мечту о хорошей будущей жизни с продуктом. Визуал работает на ощущение, а не на мысль.

## Ключевые принципы

- **Одна аудитория — одна страница.** Несколько групп покупателей → в идеале несколько страниц под разные рекламные кампании.
- **Сначала исследование:** чьи проблемы решаем, каковы они, чего хотят покупатели (спросить самих клиентов, менеджеров, поддержку).
- **Позиционирование** — ответ на «кто покупатель и какую пользу получит». Оно определяет, о каких свойствах рассказывать. Пример: термос для туристов (прочность, лёгкость, крепление к рюкзаку) ≠ для офиса (любимые напитки, не прольётся на клавиатуру, держит тепло весь день) ≠ для автомобилиста (одной рукой, в подстаканник, жара/мороз). Позиционирование отражается и в визуальном стиле.
- **Порядок работы — визуал первым:** 1) желания, цели, опасения читателя; 2) как визуализировать ответ продукта на них; 3) эмоциональная тональность (светлое/тёмное, эко/техно, мягкое/брутальное); 4) поясняющий текст к каждой визуализации; 5) ответы на вопросы; 6) приглашение к сделке. Ошибка — написать текст, а потом «разбавить» картинками.
- **Длина не страшна, страшно «про себя».** Читают сколько угодно, пока речь о читателе; бросают, когда речь о компании.

## Структура

```
1. ЗНАКОМСТВО (первый экран)
   [Главное фото/видео продукта, красиво, в обстановке целевого сценария]
   [Название + родовое слово: «термос», «курс», «приложение»]
   [Полезное действие / позиционирование: «для учёбы и офиса»]
   [Цена — только если она преимущество. Кнопка «Купить» — если хотите сразу задать рекламный контекст]

2. АРГУМЕНТАЦИЯ (3–5 «этажей», по одному на аргумент, экран–полтора каждый)
   [Большая информативная иллюстрация аргумента — главный герой]
   [Заголовок: свойство в терминах задачи читателя]
   [Короткий текст: ситуация из жизни читателя + технология, которая её решает]
   [По вкусу: крупная цифра/факт, не противоречащие иллюстрации]

3. ПОДРОБНОСТИ (визуально «второстепенно»: мельче, колонки, карточки, белый фон)
   [Факты, не вошедшие из-за позиционирования; иконки допустимы здесь]
   [Характеристики — свёрстанной таблицей (PDF — только как дополнение)]
   [Ответы на вопросы: доставка, гарантия, оплата, продавец]
   [Отзывы — в основной колонке, не в узких карточках]

4. СДЕЛКА (на плашке-цветном фоне)
   [Что именно покупаете: комплектация, сроки, гарантия, порядок заказа]
   [Цена + приёмы ценности]
   [Кнопка следующего шага: купить, заявка, предзаказ]
```

### Каждый «этаж» аргументации должен
- рисовать в голове картинку ситуации;
- не противоречить иллюстрации;
- связывать техническое свойство с задачей читателя.
Визуальная иерархия: иллюстрация → заголовок → акценты → текст, подтверждающий увиденное. Текст не выталкивает картинку (длинный — под иллюстрацию или сократить).

### Отзывы — по схеме
Кто автор и чем занят → зачем покупал, чего ждал → как пользуется, что не оправдалось → итог, совпали ли ожидания → нюансы → кому рекомендует и кому нет. Цель — помочь взвешенно решить, а не похвалить. Даже негативный, но конкретный отзыв полезен. Получать такие — наводящими вопросами («достоинства/недостатки»).

### Приёмы сделки (чтобы цена казалась меньше ценности)
Перечислить в столбик свойства/технологии; показать полный комплект с аксессуарами; разделить цену на срок гарантии или дать рассрочку; поставить рядом варианты, на фоне которых этот выгоднее; «минус рубль» (с оговоркой: усложняет счёт); привязка к общепринятым распродажам.

## Типичные ошибки → как исправить

| Ошибка | Исправление |
|---|---|
| Страница «для всех» | Одна аудитория — одна страница |
| Рассказ о компании и её преимуществах | Рассказ о читателе и его жизни с продуктом |
| Нет родового слова: «Наш продукт подарит комфорт» | Назвать категорию: «термос», «курс» |
| Сначала текст, потом картинки | Сначала визуализация аргументов, текст помогает |
| Стоки, абстрактные люди, шестерёнки, иконки «надёжности» | Демонстрация: продукт в деле, разрез, падение без повреждений, скриншот, пример отчёта, схема работы |
| Аргументы в многоколоннике с иконками | Большая иллюстрация на каждый аргумент; иконки — только в «Подробностях» |
| Свойство без ситуации: «Защита по технологии X» | Описать момент, когда это пригодится |
| Хвалебные отзывы «Всё отлично!» | Отзывы о реальном использовании, с минусами |
| Короткие ответы спрятаны под клик | Прятать только длинные ответы и спецификации |
| Название, противоречащее назначению | Название отражает назначение или хотя бы не спорит с ним |
| Бесконечная полировка без запуска | Выпустить, замерить, улучшать итерациями; тестировать варианты |
| Опора на мнения коллег/экспертов | Опора на данные реальных продаж |

## Примеры

**До (экран аргумента):**
> Инновационная технология SealTech. Высочайшее качество. Надёжность.

**После:**
> **Не прольётся на ноутбук**
> Сосед задел термос локтем — он упал прямо на клавиатуру, но не вытекло ни капли: крышка SealTech закрывается герметично. Держите термос рядом с компьютером и не переживайте.
> *(Иллюстрация: термос лежит на клавиатуре, крупно — сухие клавиши.)*

**До (отзыв):** «Отличный термос, всем доволен!»
**После:** «Брала для офиса, теперь он живёт у меня на столе. Хватает на две кружки, моется под краном. Минус: носить из дома тяжеловато — для дороги взяла бы поменьше».

## Чеклист перед отправкой

- [ ] Выбрана одна аудитория; позиционирование сформулировано: кто покупатель и какая польза.
- [ ] Первый экран: продукт виден, названа категория, понятно полезное действие.
- [ ] 3–5 аргументов, у каждого — своя информативная иллюстрация и заголовок о задаче читателя.
- [ ] Нет стоков и пустых иконок в основной части.
- [ ] Текст везде о читателе, а не о компании.
- [ ] Подробности визуально отделены и отвечают на вопросы (гарантия, доставка, оплата, характеристики).
- [ ] Отзывы конкретные, с контекстом использования, в основной колонке.
- [ ] Сделка: что покупаю, комплектация, условия, цена, кнопка; применены приёмы ценности.
- [ ] План запуска: опубликовать, замерить, тестировать варианты.
