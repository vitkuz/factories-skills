# Чек-листы: быстрый проход по всем уровням

Загружай этот файл первым. Если пункт сработал и нужна техника исправления или исключения — открой соответствующий раздел большого справочника (`text.md`, `sentence.md`, `word.md`) через поиск по названию правила, а не целиком.

## Уровень текста (польза, структура, введение, тон, глубина)  (подробно: `text.md`)

**Опора**
- [ ] Ясно, для кого текст (узкий сегмент, не «для всех»).
- [ ] Формулируется полезное действие: решает проблему или даёт эмоцию; не «проинформировать».
- [ ] Нет «внутренней кухни» и хвастовства усилиями.
- [ ] Каждый раздел работает на обещание; лишнее вынесено или удалено.
- [ ] Заголовок и введение отражают полезное действие; заголовок прагматического текста прямой и конкретный, без игры.

**Структура**
- [ ] Тип структуры соответствует материалу (новость / история / инструкция / подборка / обзор / рассуждение).
- [ ] Длинный текст начинается с договора с читателем.
- [ ] Подзаголовки информативны, единообразны там, где нужно; негативная модальность продублирована в каждом.
- [ ] Вложенность ≤ 1 уровня.
- [ ] Новость: главное наверху; «зачем» не похоронено под «кто».
- [ ] История: герой-человек, внешние события, ровная хронология, только работающие детали, герои не выдуманы.
- [ ] Инструкция: шаги в порядке выполнения, подготовка — в первом шаге, есть общая карта этапов.
- [ ] Отчёт/деловой текст: результат первым, не хроника.
- [ ] Финал есть, текст не обрывается на последнем модуле.

**Введение и заключение**
- [ ] Введение без шаблонных зачинов, сразу к делу, содержит факт/пользу/интригу.
- [ ] Заключение не повторяет подзаголовки; меняет модальность, даёт «что делать сейчас» или взгляд с обратной стороны.
- [ ] Ссылки с понятным описанием, не на «здесь».
- [ ] Реклама в конце — прямая, без извинений и без давления.

**Тональность**
- [ ] Тон нейтральный, если нет причины иного.
- [ ] Нет назидания, обвинений, категоричности, заискивания, восторга без фактов.
- [ ] Нет фальши: мотивы названы честно, нет искусственного персонажа.
- [ ] Тон согласован с площадкой и другими каналами.

**Глубина**
- [ ] Один уровень подготовки читателя на весь текст.
- [ ] Абстракции распакованы примерами из мира читателя.
- [ ] У советов есть «как».
- [ ] Есть хотя бы один антипример, нюанс или взгляд «от обратного».
- [ ] Нет выдуманных фактов, примеров и историй.

## Уровень предложения  (подробно: `sentence.md`)

**Действие и герой**
- [ ] В предложении есть конкретный деятель и действие? Можно «снять кадр»?
- [ ] Связки «осуществлять/проводить/обеспечивать/реализовывать + отглагольное» → глагол.
- [ ] Страдательный залог («было сделано», «-ется» в пассиве) → действительный, если деятель важен; акцент не сместился?
- [ ] Глаголы-состояния (является, находится, имеется, позволяет, приводит к, указывает) прячут действие? Вернуть действие или заменить тире.
- [ ] Абстракция подкреплена примером «кто-то делает что-то»? Пример не уводит в сторону и не меняет сюжет?
- [ ] Деятель не добавлен механически там, где он очевиден (механики, коммунальщики, облака)?

**Перегруз**
- [ ] Одна мысль и один главный герой на предложение?
- [ ] Нет вставок «курсором назад» (даты, регалии, обстоятельства, причастные обороты между подлежащим и сказуемым)?
- [ ] Подлежащее и сказуемое рядом и близко к началу?
- [ ] Синонимичные однородные слиты в одно; оценки заменены фактами; 3+ однородных — обобщение или перечень?
- [ ] Хронология прямая, без шагов назад внутри предложения?
- [ ] Бессоюзные части без связи разделены точкой?
- [ ] Нет лесенки придаточных глубже двух уровней?
- [ ] Отступления («кстати», скобки, «который», «то есть») — либо отдельный абзац, либо удалены?
- [ ] Парные союзы («как…, так и», «не только…, но и», «если…, то» с вложениями) упрощены?
- [ ] «Сказал, что / я считаю, что / мы видим, как» свёрнуты, где возможно?

**Абзац**
- [ ] Один абзац — одна тема; первое предложение заявляет её ключевыми словами?
- [ ] Абзац не начинается с «И/Но/Например/Здесь/В этой ситуации/Поэтому»?
- [ ] Чтение одних первых предложений даёт картину всего текста?
- [ ] Длина 3–9 строк, нет серии однострочных; нет «полотна» без деления?
- [ ] Последнее предложение подводит итог или ведёт к следующему абзацу; нет пережёвывания одной мысли?
- [ ] Нет рубленого однообразного синтаксиса — длина и начала предложений чередуются, связки на месте?

**Перечень**
- [ ] Перед перечнем обобщающая фраза с двоеточием, без «Вот что:»?
- [ ] Пунктуация: строчная буква, запятые или «;» (если внутри элементов есть запятые), точка в конце?
- [ ] Элементы параллельны по грамматике и порядку частей; нет выбивающегося по длине элемента?
- [ ] Общее для всех элементов вынесено за перечень?
- [ ] Элементы начинаются с ситуации читателя («Если…», «Для…»), а не с термина автора?
- [ ] Элемент-абзац превращён в абзац; много параметров — таблица?

**Канцелярит**
- [ ] Суть в начале, основание — в конце / отдельно («Основание — …»)?
- [ ] Процессы заменены конкретными делами?
- [ ] Заголовок передаёт суть, а не «Уважаемые…/Внимание»?
- [ ] Есть шаг деятельной заботы (адрес, ссылка, что делать дальше, альтернатива при отказе)?
- [ ] Канцелярит оставлен только там, где оправдан (претензия, формальный шаблон, обязательная структура)?

**Финальная проверка**: прочитать вслух. Если звучит натужно после правки по правилам — переписать естественно; живой поток важнее формального соответствия.

## Уровень слова  (подробно: `word.md`)

- [ ] Для каждого подозрительного слова: удаляется без потери смысла в *этом* тексте? Да → удалить. Нет → оставить. Не удалять механически по списку.
- [ ] Вводные между запятыми: удалить; важную оговорку встроить в предложение. Нет ли «очевидно/не секрет/как известно» без факта?
- [ ] «По-моему», «честно говоря», «точнее/вернее» — убрать, если нет противопоставления чужому мнению или осознанной интонации.
- [ ] «Во-первых/во-вторых» → абзацы; цифры — только для инструкций и пунктов, на которые ссылаются.
- [ ] Важное в скобках → вынести в предложение; «кстати» → удалить или связать по смыслу.
- [ ] Много запятых и придаточных → удалить лишнее уточнение, свернуть в слово, разбить на предложения; убрать оправдательный тон.
- [ ] «Более/около/примерно/не менее» → круглое или точное число, дата вместо «более N лет»; большие числа округлены, есть понятный масштаб.
- [ ] «Топ-N», «один из ведущих» → конкретное место или польза от масштаба (кроме тендеров).
- [ ] Некий, какой-то, кое-что, многие, ряд, различные, широкий спектр → удалить или назвать конкретно (кроме случаев, когда неизвестность — суть).
- [ ] Заумь и «-ировать/-ция» → простое слово или действие; термины по делу оставить; псих. термины в бытовом смысле убрать.
- [ ] Оценочные прилагательные/наречия → факт («можно вписать в договор»), сценарий, демонстрация; объективные свойства и термины оставить.
- [ ] Факты проверены: не пустые (понятны читателю), не «факты величия» (полезны именно этому читателю).
- [ ] Усилители (очень, максимально, абсолютно, совершенно, настоящий, самый) → удалить.
- [ ] Тест «закрой название»: текст узнаваем без имени компании?
- [ ] Штампы: сочетание знакомо? ломается при замене слова? подходит кому угодно? → сократить до слова или раскрыть смысл деталями.
- [ ] Паразиты времени в начале предложения → удалить, актуальность доказать фактом.
- [ ] После чистки текст не пустой? Если пустой — наполнить: факты, условия, сценарии, польза для читателя.
